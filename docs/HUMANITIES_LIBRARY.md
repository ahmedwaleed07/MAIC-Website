# Translation and professional-skills expansion

Five additional specialties: translation, marketing, public relations, critical thinking and strategic management. Human resources remains one existing category; nine additional HR books are appended rather than creating another category.

The expansion adds54 distinct free full-PDF books and substantial guidebooks. Each of the six requested areas receives9 new entries. Translation receives9 books in9 different languages including Arabic; each resource concerns translation skills or practice rather than merely language learning or translated literature.

All previously published120 entries remain intact. The resulting catalog contains174 entries across15 specialties, including21 HR entries. PDF language labels use localized language names. Original source/publisher links are retained. Unknown years and unsupported author biographies remain explicitly unavailable; missing covers use the existing MAIC design.
