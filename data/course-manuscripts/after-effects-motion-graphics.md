## 02 — Motion Graphics With Purpose

Motion graphics combine graphic design and changes over time to communicate a message. Animated titles, diagrams, icon sequences and data explanations can clarify information when their timing and hierarchy are deliberate. Motion should support comprehension, not distract viewers or falsely suggest facts. A complicated effect does not compensate for incorrect dates, inaccessible text or an unclear narrative.

Learners will create a project brief, prepare graphic assets, understand the composition and layer model, animate properties with keyframes, control interpolation and timing, work with shape and text layers, apply masks and mattes, coordinate sound, prepare a clean deliverable and verify exports. The course builds an original short public-information animation using fictional data; it does not reuse another school’s branded project.

**Ten-hour guided plan:** Orientation 30 minutes; pages 3–10 at 55 minutes each (440 minutes); practical animation on page 11 for 90 minutes; final review on page 12 for 40 minutes. Total 600 minutes. Learners need suitable editing access for hands-on work; if software is unavailable, an annotated storyboard can demonstrate the same decisions.

**Starter:** Sketch three frames announcing an invented community workshop. Decide what readers must know, then plan how motion reveals the title, date and action.

## 03 — Project Planning, Format and Asset Organization

Start with an animation brief specifying audience, communication objective, visual identity, total duration, resolution, aspect ratio, delivery destination, frame rate, script, captions and required rights. A phone story may need a vertical layout while a presentation screen needs a wide version. Do not select one format automatically for every platform; graphics and text must remain visible in the actual published environment.

Organize original media into dedicated folders for illustrations, audio, video, fonts, reference documents and rendered outputs. Preserve editable source assets and appropriate licenses. A project file can reference external media paths, so relocating files carelessly may break a composition. Document file locations and create a versioned backup before major experiments.

Use a storyboard or animatic to test sequence and duration. For a 20-second notice, identify the essential facts and the time each needs to remain readable. An image may look attractive in a still frame but become unreadable after rapid movement. Plan a restrained motion hierarchy before adding plugins.

**Fictional example:** The notice must communicate an event name, date, start time and registration website. The script should not assume a fictional link is active; mark it as a classroom placeholder.

**Practice:** Prepare a six-field production brief, an asset log and a five-beat storyboard with time codes.

## 04 — Compositions, Layers and Timeline

An After Effects composition is a framework for an animation with its own dimensions, frame rate, duration and timeline. Adobe's 2026 documentation describes layers that can include video, still images, text, vector graphics, audio and lights. Assets are introduced as layers into a composition and organized in space and time. Nested compositions can help manage complexity but should not obscure ownership of essential content.

Set composition properties deliberately before adding many assets. A wrong frame rate can cause unwanted timing assumptions; an incorrectly oriented composition may crop mobile text. Layer order affects which objects appear in front and how transparency reveals underlying imagery. Name layers by function, such as Main Title or Schedule Icon, instead of leaving dozens of unnamed copies.

Use timeline markers or comments for important narrative events. Create a simple sequence: background, title, date and final call to action. Verify how long each appears and whether the ending has enough reading time. A layer can exist in the project without being visible at every point of the composition.

**Fictional example:** A title layer begins at 0 seconds, a schedule layer starts after two seconds and a contact card remains until the end. Exact timing is checked by preview rather than inferred from static images.

**Practice:** Create a five-layer composition, rename every layer, change layer timing and compare a wide and a vertical format.

## 05 — Keyframes, Time and Easing

Keyframes specify property values at particular moments. Position, scale, opacity and rotation can change over time. An object moving from X=0 to X=200 over two seconds has a nominal average horizontal speed of 100 position units per second, even if easing makes instantaneous speed vary. Animation should be evaluated for legibility, pacing and intention rather than only numerical smoothness.

Interpolation determines what happens between keys. Linear interpolation produces steady progression between two values. Eased motion accelerates or decelerates and may look more natural, but aggressive easing can conceal a critical label. Examine the graph or speed behavior in the installed editor when needed. A hold keyframe can preserve a stepped state instead of a smooth transition.

Animate with restraint. A public-service notice may use a title fade and a controlled icon movement, while important numbers remain stationary long enough to read. Avoid unplanned motion that induces discomfort; provide reduced-motion alternatives in interactive delivery where practical.

**Worked arithmetic:** At 25 frames per second, a two-second animation spans 50 frame intervals. The location of each keyframe should be checked against the composition's timebase.

**Practice:** Animate one title using position and opacity keys, compare linear and eased timing and explain which helps the reader.

## 06 — Shape Layers, Text and Hierarchy

Shape layers can contain paths, fills, strokes and transforms suitable for precise graphic elements. Text layers support animated typography and legible messages. A reusable style can keep headings, body labels and numbers consistent. Prepare artwork to remain clear at intended screen size, especially when resizing between horizontal and vertical formats.

Animate text to reinforce meaning. Word-by-word or character animation can be engaging, but the full sentence should remain available long enough for comprehension. Avoid excessive tracking, thin fonts over noisy imagery and unnecessary 3D rotation of critical information. Captions and language versions may need separate timing and screen space.

An effect that improves design at desktop size may harm mobile readability. Check the smallest delivery screen. Use actual date and time values only when verified. If an event number is provisional, label it accordingly. Make sure the approved brand logo retains its fixed typography rather than changing its font with the language selector.

**Fictional example:** A title is revealed by a subtle shape wipe, then remains still while supporting schedule text appears. The animation prioritizes the date over decorative particles.

**Practice:** Build an original text-and-icon card and test two timing patterns with a viewer.

## 07 — Masks, Track Mattes and Compositing

Compositing combines multiple layers into one image. Alpha transparency controls which pixels are visible. Masks can define a visible region of a layer; track mattes can use another layer's visual or alpha information to control visibility. The exact UI and track-matte behavior may differ by After Effects release, so consult the current help rather than copying an old screenshot.

Use masks to create intentional reveals and corrections, not to fabricate factual evidence. A simple title can appear as a moving rectangle reveals it. Feathering softens an edge, while too much softness may reduce clarity. Track matte references should be named so reviewers understand which layer controls the reveal.

Organize dependencies carefully. If the matte layer is removed or changed, the reveal may break. Preview the animation before and after editing linked elements. For documentary content, a matte should not make an archival visual appear as a photograph of the current event without clear labeling.

**Fictional example:** An icon is revealed through a moving circular mask at the start of an instructional clip. The effect is illustrative and does not claim a real-world change occurred.

**Practice:** Compare a masked reveal and a simple opacity fade, recording both readability and project complexity.

## 08 — Color, Sound and Motion Accessibility

Color creates focus and coherence but can be misleading if it is the only means of differentiating categories. Use text labels as well as colors for critical statuses. Keep contrast sufficient for captions and small numeric information. Audio supports rhythm and comprehension, yet background music should not drown out spoken details. Use rights-cleared audio and respect contributor privacy.

Motion accessibility requires attention to rapid flashing, intense movement and time to read. Not every output system supports a reduced-motion preference; create a simpler or static alternative where appropriate. The WCAG guidelines include requirements related to flashing and animation for web content, but an offline video should also be tested for real viewer usability.

Synchronize changes with narration only when it helps comprehension. A fast visual reveal may precede the spoken explanation and confuse viewers. Captions must reflect the actual wording and timing. Generated transcripts can make mistakes in proper names, figures and languages.

**Fictional example:** A video compares three invented service statistics. The animated bars use direct labels and do not rely on red-green contrast alone.

**Practice:** Create an accessibility checklist for readable text, audio level, flashing, captions and a static information equivalent.

## 09 — Effects, Expressions and Controlled Reuse

After Effects offers animation effects, presets and expressions that automate or modify visual properties. A preset may speed work but does not guarantee the result is appropriate to the message. An expression is code that can link or calculate property values; complexity should be introduced only when it provides a repeatable benefit. Keep expressions documented and inspect generated motion for failures.

Group related layers or use nested compositions to reuse a design. This can help when producing multiple event cards with the same branded structure but different approved titles and dates. Avoid changing a fixed brand wordmark in one localized composition. Inconsistent source files can produce different animation behavior across versions.

Test frame rate, timing and actual rendered outcomes after effects are added. Heavy effects can increase render time and change transparency or edge behavior. A template with invisible text at export is not ready for release, no matter how convincing the preview was.

**Fictional example:** A master schedule card uses a reusable background and animation treatment. Each new version must still verify the actual service hours before export.

**Practice:** Reuse one nested composition in two outputs, documenting the editable fields and testing its source dependencies.

## 10 — Preview, Rendering and Quality Assurance

Preview the animation with real timing and sound before export. Inspect the first and final frames, title duration, frame rate, legibility, transition behavior and audio synchronization. Rendering generates final frames; encoding creates a deliverable file. Preserve the editable project and source assets because a flattened video is not a complete backup of all animation layers.

Choose output settings according to destination, aspect ratio and delivery requirements. Adobe documents a workflow of organizing footage, arranging layers, animating properties, previewing and rendering. A file that successfully renders may still contain spelling errors, clipped captions, unwanted transparent regions or a wrong date. Test the encoded result on the actual kind of screen.

Quality control should include content accuracy and rights, not just technical polish. A motion graphic showing a public schedule needs the same source verification as a written notice. When a material error is found after release, create a corrected, clearly versioned deliverable and update the affected distribution channels.

**Fictional example:** The draft caption says an invented workshop starts at 10:30 while the checked brief says 10:00. The timeline graphic is revised before the final export.

**Practice:** Write a ten-point rendering checklist and record one issue discovered outside the editor preview.

## 11 — Worked Project: A 20-Second Information Animation

**Entirely fictional project.** A community center announces an introductory workshop, with the title, day, start time and registration instruction supplied on a fictional source sheet. The assignment is a 20-second horizontal animation and a mobile adaptation. No real event, venue or registered participant is represented.

Plan five narrative beats: introduction, subject, event information, one supporting icon and final action. Use a five-layer composition, with text, shape and background elements. Animate one layer's position and another's opacity, comparing linear and eased motion. Include a masked reveal only if it improves comprehension. Keep the schedule card still long enough for reading. Add licensed audio only if available.

**Timing example:** A 20-second project at 25 frames per second has 500 frame intervals in its nominal duration. The five beats might occupy 3, 4, 5, 3 and 5 seconds, totaling 20. A frame-count calculation does not guarantee every word can be read; test with the actual audience.

Prepare a vertical adaptation that rearranges elements instead of cropping critical dates. Create a static summary and a caption text file. Preview and render a draft, then inspect it on a phone. Document version, license status and corrections.

**Deliverables:** Brief, storyboard, organized project, keyframe description, sound/rights notes, horizontal and vertical review versions, accessibility notes and final QA log.

## 12 — Practice Assessment and Originality References

**Self-test:** (1) What is a composition? (2) What does a layer represent? (3) What do keyframes specify? (4) How do linear and eased motion differ? (5) Why should text remain visible long enough? (6) How does a mask differ from a track matte? (7) Why are audio rights relevant? (8) What can an expression control? (9) Why is a rendered movie not equivalent to a source project? (10) Why should every exported animation be checked for factual accuracy?

**Final project:** Produce or storyboard an original 20-second public-information animation from fictional approved data. Include a brief, timing chart, organized compositions, original graphics, at least two animated properties, one justified transition or mask, sound and accessibility checks, a horizontal and vertical delivery plan and an annotated quality log.
