## 02 — Modeling Rooms for Better Spatial Decisions

SketchUp can help interior designers test dimensions, furniture placement, movement paths and visual concepts in three dimensions. The model is a representation of a proposed space, not proof of safety or code compliance. A trustworthy model starts with measured dimensions and a functional brief, then organizes geometry for review. Attractive presentation styles should come after the room is usable.

Learners should be able to set model units, create a measured room envelope, use drawing and Push/Pull tools, organize related geometry into groups and components, apply appropriate tags, build furniture approximations, test circulation, define scenes, annotate dimensions and prepare visuals for a design review. They will also explain what a concept model cannot establish without specialist assessment.

**Eight-hour study route:** Introduction 20 minutes; eight instructional sections (pages 3–10) at 45 minutes each (360 minutes); applied modeling on page 11 for 60 minutes; evaluation on page 12 for 40 minutes. Total 480 minutes. The course assumes access to a SketchUp edition supporting the basic modeling tools; where access is limited, learners can use scaled sketches and screen annotations.

**Starter:** Sketch a 5 m by 4 m reading room and mark doors, windows and desk locations before creating 3D geometry.

## 03 — Units, Axes and Accurate Initial Geometry

Begin by setting units and drawing with known dimensions. SketchUp uses red, green and blue axes to describe spatial directions and supports numeric dimension input for many drawing operations. A model drawn approximately with a mouse may look proportionate while being too narrow for actual furniture. Establish a unit convention and keep it in the project notes.

Create the floor boundary using a rectangle with dimensions from an existing-conditions drawing. Build wall representations with enough detail for the exercise but avoid inventing wall thicknesses and structural conditions as certified facts. Draw the room envelope, then mark known openings. Do not assume the door location from a photo is precise. Record which dimensions are verified and which remain provisional.

View the model from above and in 3D. The top view helps compare positions and clearances, while an angled view helps understand volume and room proportions. The modeling axes are not a substitute for the building's actual physical orientation or site survey. Document the drawing revision and note any uncertainties.

**Example:** A floor rectangle is 5 × 4 m, giving 20 m². Raising walls visually does not increase this floor area. If 2 m² is reserved for fixed storage, the remainder is 18 m² before furniture and circulation.

**Practice:** Make a measured floor rectangle, verify its dimensions and annotate the unverified openings.

## 04 — Faces, Edges, Push/Pull and Clean Geometry

SketchUp's model geometry often begins with edges and faces. Closed coplanar boundaries can form a face; the Push/Pull tool can extrude a face to produce three-dimensional volume. A missing edge or an unintended connection may prevent the correct face from forming. Check geometry before repeating the operation. Use numeric input for important heights rather than dragging until the wall looks realistic.

Construct a simple room with a floor plane and wall volumes, then add a window or door opening by a controlled modeling approach suitable to the installed edition. Be careful about model orientation and surface visibility; missing faces can create confusing results. Keep the geometry simple enough to revise when a client changes a furniture dimension.

As detail increases, raw geometry can stick together unexpectedly. If the model's floor, furniture and wall edges remain loose in one context, editing one object can alter another. Organize objects into groups or components before creating many repeated items. Preserve a clean base room version for comparison.

**Fictional example:** A desk is represented by a box-like tabletop and four legs. It is created as a separate group so moving it does not pull wall geometry.

**Practice:** Extrude two measured faces, identify one accidental connection and correct the geometry organization.

## 05 — Groups, Components, Tags and Model Organization

Grouping protects related model geometry from unintended interactions. Components can represent repeated objects, such as matching chairs, so their consistent geometry can be managed more efficiently. When an individual item needs a different design, check how its component relationship behaves before editing all instances. Organize the main objects with descriptive names.

Tags can control visibility and help isolate furniture, walls, services and design alternatives. They do not replace proper grouping of raw edges and faces. Keep model structure simple and consistent. Hiding an object for a presentation does not mean it is removed from the design; an invisible shelf may still affect real circulation.

Use the Outliner or equivalent organization panel where supported to locate object hierarchies. A large interior project benefits from a predictable naming convention such as Room / Existing, Furniture / Desks and Option B / Storage. The model should make revision and review easier, not merely increase visual complexity.

**Fictional example:** Six matching chairs are instances of one component. They can be positioned individually, while the shared geometry stays consistent unless a deliberate unique variation is created.

**Practice:** Create two groups, one repeated chair component and three visibility categories. Test hiding furniture without deleting source geometry.

## 06 — Furniture, Circulation and Space Planning

Model furniture to believable dimensions so the room layout can be evaluated. A table footprint alone is not enough; chairs need space to move, cabinets need opening clearances and users need paths between areas. Mark furniture in use, not only when neatly tucked beneath a desk. Check doors and windows in relevant states.

Layout choices should follow the room's tasks. A reading room needs quiet seating, book access and a clear route to the exit. A collaborative room may prioritize a shared table and flexible seating. Test two alternatives rather than assuming a visually balanced arrangement is best. Use the same room boundary when comparing them so the difference is meaningful.

Do not substitute a screenshot of a wide-looking aisle for a measured compliance assessment. Applicable physical accessibility and fire rules depend on building use and location; obtain professional review for real construction. In the classroom model, label uncertain clearances for later verification.

**Fictional example:** Option A places a central table and six chairs. Option B locates desks along two walls. The model compares daylight, movement and storage access without declaring either arrangement code-approved.

**Practice:** Arrange a six-seat layout, draw the main circulation path and list three conditions needing site measurements.

## 07 — Materials, Lighting Context and Visual Styles

SketchUp materials can help distinguish floors, walls, furniture and conceptual finishes. An applied color or wood texture is an appearance proposal, not a verified product specification. Actual fire resistance, slip performance, emissions and durability require manufacturer data and relevant tests. Keep materials organized and consistent with the design brief.

Model sunlight or shadows only with awareness of geographic location, time and project orientation. A visually dramatic shadow is not a measured daylight or energy study. Use visual styles that communicate the intended design without hiding necessary geometry. Provide at least one neutral view where dimensions and circulation are easy to inspect.

Color selection should account for actual light and the size of the finished surface. An on-screen material preview may not match a built sample. A client presentation can include concept textures and realistic atmosphere, but should also clearly state which items are placeholders pending approval.

**Fictional example:** A pale floor and navy accent wall are proposed for the reading room. The presentation notes that final finish samples and lighting conditions must be checked before purchasing.

**Practice:** Apply a three-material palette, capture a neutral and a shaded view, and identify which claims the render cannot support.

## 08 — Scenes, Camera Views and Review Documentation

Scenes save useful view configurations and can help compare the same space from multiple perspectives. A plan-like top view makes spatial relationships easy to understand; an eye-level view explains occupant experience; a perspective view can help the client imagine the final room. Use a consistent set of scenes across design alternatives so a change in camera angle does not masquerade as a change in room quality.

Add dimensions or annotations where supported, ensuring they are attached to the correct geometry. For detailed printable sheets, a compatible LayOut workflow may be available in some SketchUp subscriptions, but the course does not assume every learner has that entitlement. A screenshot can support discussion, yet a dimensioned model and source project remain essential for future revision.

A review package should identify which version is being shown, whether the measurement source was checked, and what safety or accessibility items remain unresolved. Do not hide inconvenient furniture in a scene without documenting the design's actual contents. Keep a clear difference between a presentation view and a technical review view.

**Fictional example:** A pair of scenes shows the same seating arrangement from above and near the entry. The top view reveals a tight corner that was not obvious in the perspective view.

**Practice:** Create three named scenes with identical geometry, one dimension annotation and a short review note.

## 09 — Editing, Alternatives and Responsible Modeling

Interior design is iterative. When a client requests a new table size or a different storage location, update the model while preserving the existing measured room. Avoid moving the wall to make furniture fit unless the architectural change has been authorized. Duplicate an option or preserve a version before major edits, so stakeholders can compare consequences.

Use groups and components to manage changes predictably. A component edit may affect multiple chairs; a uniquely modified instance should be intentional. Keep model names and visibility settings coherent. Inspect the result after resizing: a desk that gains 200 mm may now block an important route.

Document decision quality. A scheme may appear beautiful but fail the target seating count, exceed the available budget or obstruct a doorway. Rank alternatives against the brief, not solely by aesthetic preference. Capture assumptions and conditions requiring expert review.

**Fictional example:** Enlarging the shared table makes one chair overlap the door swing. The designer reconsiders the table or layout and records the compromise rather than ignoring the conflict.

**Practice:** Make two design alternatives and record dimensions, user needs and three risks for each.

## 10 — Export, Model Quality and Handoff

A useful design handoff should preserve the editable SketchUp project and provide clearly named review views or documents. File compatibility depends on receiver software and available export options; test needed formats rather than assuming every 3D application retains full component structure. Final visuals should be readable on the intended device and provide context for scale and orientation.

Before export, review units, groups, face orientation, hidden geometry, scene consistency, dimensions, copyright permissions and relevant material notes. Avoid presenting an impressive render with no indication of space size. Check that the approved logo or project identity remains correct in any presentation sheet. When a correction is made, update the source and derivative images to avoid conflicting versions.

Model performance also matters. Excessive decorative geometry, repeated high-polygon furniture and unnecessary textures can slow editing. Use simplified components appropriate to the decision. A modeling tool should support review rather than produce a huge file that stakeholders cannot open.

**Fictional example:** The final package includes an editable model, three scenes, a dimensioned plan image and a list of unresolved site measurements.

**Practice:** Create a ten-point model handoff checklist and test a recipient opening the chosen review file.

## 11 — Worked Case: Six-Seat Reading Room

**Entirely fictional studio assignment.** A community room has nominal interior dimensions of 5 m by 4 m. It needs seating for six, small book storage and clear circulation. The window and door are indicated on an illustrative sketch, but their exact dimensions require verification before real work. Two schemes will be built in SketchUp and reviewed under the same assumptions.

Start with a 20 m² floor and simple wall envelopes. Group the room elements. Create a desk and chair component based on clearly stated classroom dimensions, not an unknown manufacturer's exact product. Build a central shared-table option and a wall-desk option. Mark occupied chair spaces and paths. Use visibility controls to compare the alternatives and create three named camera scenes.

**Illustrative arithmetic:** If the room area is 20 m² and fixed storage occupies 2 m², nominal remaining area is 18 m². Dividing 18 by six yields 3 m² per requested seat before accounting for paths, access and other furnishings. This ratio is not an occupancy or accessibility certification.

Apply a limited palette and prepare one neutral technical view with dimensions and one visual concept view. Identify unresolved fire/accessibility requirements and the need to verify real product sizes. Keep an editable source model and a version history.

**Deliverables:** Brief, model organization, furniture components, two options, measurement notes, scenes, visual palette and a reasoned recommendation.

## 12 — Review Questions, Model Project and References

**Self-test:** (1) Why set units before modeling? (2) What do edges and faces represent? (3) What does Push/Pull do? (4) How do groups and components differ? (5) Why do tags not replace geometry organization? (6) What should be included in circulation planning? (7) Why is a material texture not an engineering certificate? (8) What do scenes help communicate? (9) Why must model versions be preserved? (10) What should be checked before handoff?

**Final project:** Develop an original SketchUp concept for the fictional reading room. Include measured assumptions, a named model hierarchy, basic furniture components, two functional layouts, annotated circulation, a neutral technical view, a presentation scene, design selection reasoning and a quality checklist. If software is unavailable, produce accurately dimensioned plan and perspective sketches with the same logic.

**Practice rubric:** Units and source geometry 20%; clean organization and components 20%; space planning and circulation 25%; communication scenes and materials 15%; versioning and responsible verification 20%. This is a learning rubric, not official professional qualification or approved building compliance.
